# 35. Search Insert Position

- **Difficulty:** Easy
- **Topics:** Array, Binary Search
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Binary search for the lower bound: the first index whose value is at least the target.

## Complexity

- **Time:** O(n) for linear scans; O(log n) for binary search.
- **Space:** O(1) auxiliary space.
