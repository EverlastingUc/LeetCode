# 66. Plus One

- **Difficulty:** Easy
- **Topics:** Array, Math
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Propagate carry from the least significant digit. If all digits are 9, create a new leading 1.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary space (excluding any returned output allocation).
