# 2011. Final Value of Variable After Performing Operations

- **Difficulty:** Easy
- **Topics:** Array, String, Simulation
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Each operation increments or decrements the variable; inspect the middle character to determine the direction.

## Complexity

- **Time:** O(n) for scanning inputs; O(1) for arithmetic-only operations.
- **Space:** O(n) only for returned arrays; otherwise O(1) auxiliary space.
