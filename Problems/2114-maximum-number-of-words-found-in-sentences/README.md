# 2114. Maximum Number of Words Found in Sentences

- **Difficulty:** Easy
- **Topics:** Array, String
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Count words in each sentence by counting spaces and adding one, then take the maximum.

## Complexity

- **Time:** O(n) for scanning inputs; O(1) for arithmetic-only operations.
- **Space:** O(n) only for returned arrays; otherwise O(1) auxiliary space.
