# 27. Remove Element

- **Difficulty:** Easy
- **Topics:** Array, Two Pointers
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Overwrite the array from the front with values unequal to the target. The write index is the resulting logical length.

## Complexity

- **Time:** O(n) for linear scans; O(log n) for binary search.
- **Space:** O(1) auxiliary space.
