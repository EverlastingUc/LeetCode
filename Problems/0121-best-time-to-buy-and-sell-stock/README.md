# 121. Best Time to Buy and Sell Stock

- **Difficulty:** Easy
- **Topics:** Array, Dynamic Programming
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Track the minimum price seen so far. At each day, compare the profit from selling today against the best profit so far.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary space (excluding any returned output allocation).
