# 169. Majority Element

- **Difficulty:** Easy
- **Topics:** Array, Boyer-Moore Voting
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Boyer-Moore voting keeps a candidate and balance; the guaranteed majority survives pairwise cancellation.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary for constant-state approaches; O(n) for hash-set or filtered-string approaches.
