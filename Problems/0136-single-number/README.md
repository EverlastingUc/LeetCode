# 136. Single Number

- **Difficulty:** Easy
- **Topics:** Array, Bit Manipulation
- **Implementations:** Python, C++, JavaScript, Java

## Approach

XOR cancels equal pairs because x XOR x is zero, leaving the unique element.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary for constant-state approaches; O(n) for hash-set or filtered-string approaches.
