# 217. Contains Duplicate

- **Difficulty:** Easy
- **Topics:** Array, Hash Table
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Insert each value into a hash set. A repeated value reveals a duplicate.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary for constant-state approaches; O(n) for hash-set or filtered-string approaches.
