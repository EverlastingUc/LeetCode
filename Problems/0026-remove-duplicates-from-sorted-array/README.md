# 26. Remove Duplicates from Sorted Array

- **Difficulty:** Easy
- **Topics:** Array, Two Pointers
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Sorted input places duplicates together. A read pointer scans while a write pointer stores each new distinct value.

## Complexity

- **Time:** O(n) for linear scans; O(log n) for binary search.
- **Space:** O(1) auxiliary space.
