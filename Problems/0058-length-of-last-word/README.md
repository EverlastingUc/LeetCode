# 58. Length of Last Word

- **Difficulty:** Easy
- **Topics:** String
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Scan backward, skip trailing spaces, then count characters until the preceding space or start of input.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary space (excluding any returned output allocation).
