# 1929. Concatenation of Array

- **Difficulty:** Easy
- **Topics:** Array
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Return the original array followed by a second copy of its elements.

## Complexity

- **Time:** O(n) for scanning inputs; O(1) for arithmetic-only operations.
- **Space:** O(n) only for returned arrays; otherwise O(1) auxiliary space.
