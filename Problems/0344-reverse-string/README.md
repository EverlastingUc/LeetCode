# 344. Reverse String

- **Difficulty:** Easy
- **Topics:** Two Pointers, String
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Swap characters at the left and right ends, moving both pointers toward the center.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary space.
