# 350. Intersection of Two Arrays II

- **Difficulty:** Easy
- **Topics:** Array, Hash Table, Two Pointers
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Count values in the first array, then consume one count for each matching value in the second array.

## Complexity

- **Time:** O(n) expected for hash-based counting; O(n) for the scans and binary search O(log n).
- **Space:** O(1) for fixed-alphabet/two-pointer methods; O(n) for hash maps or output.
