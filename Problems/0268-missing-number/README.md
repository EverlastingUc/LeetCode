# 268. Missing Number

- **Difficulty:** Easy
- **Topics:** Array, Math, Bit Manipulation
- **Implementations:** Python, C++, JavaScript, Java

## Approach

Use the arithmetic-series sum for 0 through n and subtract the sum of the provided values.

## Complexity

- **Time:** O(n).
- **Space:** O(1) auxiliary space.
